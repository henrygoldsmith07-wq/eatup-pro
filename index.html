Installation Made Simple

Get started in minutes with our automated deployment scripts

1. Clone Repository

git clone https://github.com/henrygoldsmith07-wq/eatup-pro
cd eatup-pro

2. Install Dependencies

pip install -r requirements.txt

3. Run Deployment (Optional)

# Automated setup with backup & scheduling
./deploy_production.sh

4. Start Using Master Control

# Quick scan
python master_control.py scan --drive C:

# AI-powered cleanup
python master_control.py cleanup

# Full system optimization
python master_control.py system
